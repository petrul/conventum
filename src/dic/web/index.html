A map of the source, with evidence attached. Origin tabs use the immediate source language, not a distant ancestor. Prose is an extraction candidate; “from Latin” alone does not establish inheritance. The strict filter requires an explicit inh template. Multiple origins can place a word in several tabs. Forms are grouped only where Wiktionary supplies a link or paradigm; unresolved entries remain in the database.

Finding candidates for meaning change. Word distance compares bare spellings using a multilingual model; spelling, language, polysemy, and model coverage can affect it. Definition distance compares the first attested definition for each side, without headwords. It uses only meanings present in the dump, never generated meanings or a word-distance fallback. High distance is a lead for review, not proof of historical semantic change. The highlighted ancestor supplies the displayed score.
